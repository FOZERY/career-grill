# Skills

Опубликованные скиллы репозитория находятся в подкаталогах этого каталога. Каждый скилл содержит обязательный `SKILL.md` и может иметь дополнительные reference-файлы.

- `career-grill` — проработка и защита карьерной легенды по одной роли.
- `career-cv` — топ‑50 ключевых слов специализации и ATS-bullets по одной законченной роли.
