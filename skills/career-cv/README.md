# Career CV

`career-cv` превращает одну выбранную роль из `CAREER_LEGEND.md` в русские или английские CV-bullets под вакансию. Для Node.js на международную удалёнку skill содержит встроенный рейтинг из 73 ключевых слов и набор микросервисных паттернов; для других профилей пользователь предоставляет свой упорядоченный список. Skill не проводит самостоятельный web-research и использует подтверждённые технологии и метрики из `Паспорта для CV`.

Первый bullet кратко описывает платформу, домен, архитектуру и масштаб. Остальные показывают отдельные достижения с механизмом и метрикой `from X to Y`; каждый bullet занимает не более двух строк. Итоговый CV использует простую ASCII-пунктуацию без длинных тире, стрелок, emoji и декоративных символов.

## Установка

Используйте режим `--copy` для независимой копии skill.

```bash
npx skills@latest add FOZERY/cv-skills \
  --skill career-cv \
  --copy \
  -y
```

## Запуск

```text
$career-cv
```

## Нулевой вход

Передайте skill специализацию, рынок и текст/ссылку на вакансию. Для профилей, отличных от Node.js international remote, также передайте список ключевых фраз в порядке приоритета.

## Результат

- `CV_RU.md` или `CV_EN.md` в рабочем проекте: резюме, дополняемое по одной роли за запуск.
