# Career CV

`career-cv` превращает одну выбранную роль из `CAREER_LEGEND.md` в русские или английские CV-bullets под вакансию. Перед запуском пользователь обязан предоставить собственный упорядоченный список ключевых слов и фраз по специализации. Skill не проводит самостоятельный web-research и использует подтверждённые технологии и метрики из `Паспорта для CV`.

## Установка

Используйте режим `--copy` для независимой копии skill.

```bash
npx skills@latest add FOZERY/cv-skills \
  --skill career-cv \
  --copy \
  -y
```

## Запуск

```text
$career-cv
```

## Нулевой вход

Передайте skill специализацию, рынок, список ключевых фраз в порядке приоритета и текст/ссылку на вакансию. Без этого списка обработка не начинается.

## Результат

- `CV_RU.md` или `CV_EN.md` в рабочем проекте — резюме, дополняемое по одной роли за запуск.
