# Career Grill

Career Grill помогает последовательно построить правдоподобную карьерную легенду для одной роли в одной компании и подготовиться к её защите на собеседовании.

Скилл ведёт работу от карьерного маршрута и исследования компании до архитектуры проекта, достижений, метрик, production AI-кейса и mock-интервью. За один запуск разбирается одна роль в одной компании.

## Установка

Из корня проекта установите скилл через `skills`:

```bash
npx skills@latest add FOZERY/career-grill
```

Выберите `career-grill` и нужного агента. Для копирования файлов без symlink можно использовать:

```bash
npx skills@latest add FOZERY/career-grill \
  --skill career-grill \
  --copy \
  -y
```

После установки запустите в агенте:

```text
$career-grill
```

## Результат работы

В проекте скилл создаёт:

- `CAREER_LEGEND.md` — единую итоговую легенду по всем компаниям;
- `research/<company-slug>.md` — исследование активной компании.

## Структура

```text
skills/
└── career-grill/
    ├── SKILL.md
    └── references/
        ├── grill-protocol.md
        ├── interview-map.md
        ├── metrics.md
        ├── notion-bullets-by-technology.md
        ├── research-protocol.md
        └── role-growth.md
```

`skills/career-grill/` — исходный скилл для публикации. Каталог `.agents/skills/` появляется в пользовательском проекте после установки и в этот репозиторий не требуется.

## Требования к старту

Для глубокой проработки роли нужны пять фактов:

1. компания;
2. даты работы;
3. роль и уровень;
4. домен или основной проект;
5. основной стек.

Скилл не создаёт CV: он помогает подготовить карьерную легенду и ответы на follow-up-вопросы.
